# 评审修订 02 · 简称与市场视觉重点

根据用户反馈，本轮在独立样板内移除列表、终端身份和资料区域的项目全称，只显示代币简称。全称字段与搜索匹配仍保留，不改写项目身份；链与合约仍可查看和复制。

上一版的均匀行样式、低强调数字、字母 Logo 和大面积蓝灰表面偏向后台表格。本版改为中性深色背景、更鲜明的数据对比、较大的简称与代币图形、带面积的趋势线和高对比涨跌标签。接近完成（演示阈值 90%）的项目使用左边标记与进度强调，不虚构倒计时。

市场上方增加可点击的演示动态条，使用已存在的样例成交/涨跌/进度，不展示盈利排行或真实用户数据，不自动编造事件。演示提示保留。

手机操作顺序、双主题、输入校验、确认步骤与正式前端保持隔离。109 项原有样板断言继续运行，并加入双主题各页面不出现全称的 20 项断言。视觉是否达到期望仍需审核，测试数量不代表审美评级。
