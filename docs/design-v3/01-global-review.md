# NEXNS V3 · 全局审阅与旗舰方向

本轮是五步重构的第 1 步：全局审阅、设计方向与交互样板。不是对现有卡片换肤，也不是已完成正式产品重构。批准的品牌 Logo 与产品规则保留，页面几何可以重排。

## 审阅依据与发现

对当前正式前端的发行、运行、资产、创建、协议、NEXNS、Curve 与 Operating 共八类页面，获取 1440/390 两种视口的 16 张完整截图及标题/按钮位置。证据保存在忽略目录 `test-results/v3-audit/`。工作室参考现有源代码，迁移沿用生命周期边界；本轮没有在浏览器重新遍历所有工作室标签、账户状态与迁移操作，不把基础视图审阅称作完整业务回归。用户提供的 Pump 截图作为视觉参考，不复制其社交和盈利排行功能。

1. 市场页的第一列宽度与有效内容不匹配；价格、参与人数、进度之间空白较多，关注点弱。
2. `src/data/market.ts` 的 Curve `change` 明确返回 `null`，因此涨跌为空是当前数据映射行为，不是文字颜色问题。后续需定义基于历史的真实模拟口径；本轮不修改该层。
3. Curve 图表由 `curveSeries(ledgerState(...))` 生成，横轴为储备，不能当成时间行情或 K 线。后续主图引入实际模拟成交历史，理论曲线另作切换；没有 OHLC 就不提供伪造蜡烛图。
4. 当前手机 Curve 的确认买入按钮顶部约在 1129px，操作切换约在 893px；Operating 的操作前还有个人摘要。说明“操作卡在前”不足以确保“用户立即可以操作”。
5. 当前全站是明亮、低强调、卡片式组织。主题迁移应覆盖角色、图表、弹窗、状态，而不是在末尾叠加 dark 选择器修补各页。

## 全站设计分工

| 页面         | 用户目标               | 新信息主线                                                         |
| ------------ | ---------------------- | ------------------------------------------------------------------ |
| 发行 / 运行  | 发现、比较、关注项目   | 阶段榜单 → 简称/名称 → 价格与趋势 → 阶段指标 → 操作入口            |
| Curve        | 判断价格并买卖         | 紧凑身份/报价 → 桌面图表与买卖并列；手机金额操作在前 → 进度 → 记录 |
| 迁移         | 理解当前状态与下一步   | 单一迁移状态、资产结果和可用动作；不提供强制迁移                   |
| Operating    | 参与、质押、领取       | 每个操作只展示对应余额、结果及限制；个人总览下移                   |
| 资产         | 了解持有与可执行事项   | 资产摘要 → 有余额才突出的领取 → 持仓列表；空状态不重复催促         |
| 创建         | 准确填写并确认         | 单一字段主线 → 资料预览 → 确认；固定参数置于规则帮助               |
| 工作室       | 管理自己项目与查看结果 | 项目选择 → 当前阶段 → 收益/结果 → 可编辑资料                       |
| 协议 / NEXNS | 核实公开信息和核心资产 | 精简概览、供应/合约/结算等公开结果；不呈现内部执行控制             |

## 视觉与交互规则

- 白天：#F5F7FA 背景、白色表面、#142035 主文字；夜间：#0B0E14 背景、#111620 表面、#F1F5FB 主文字。正式实现映射到共享语义 token，不逐页复制类名。
- NEXNS 蓝保持品牌与主行动角色。上涨、下跌承担市场信号；颜色之外保留符号、数字与文字。
- 使用 8–12px 控件/面板圆角，降低嵌套表面。避免所有容器 24px、大阴影、发光、毛玻璃的统一装饰。
- 数据字体为系统等宽字体，主报价 24–28px、表格 12–14px；名称与说明使用常规无衬线。
- 桌面宽画布，主要图表与约 352px 操作区并列；无重型永久侧栏。手机重新组织内容，而非压缩桌面表格。
- 买卖为 segmented control；金额输入 28px、MAX、快捷金额、预计结果和 46px 主按钮连续排列。
- 个人余额摘要放在操作底部可展开区域；解除质押/领取等对应信息进入自己的操作上下文。
- 模拟环境明确标记；正式数据不制造盈利榜、热度、人数、成交与倒计时。市场情绪来自可解释的活动变化。
- 保留链 ID + 合约身份与既定搜索优先级。样板只演示简称/名称/合约筛选，不宣称已实现正式完整搜索。

## 可审核样板

`index.html`、`preview.css`、`preview.js` 为独立设计样板，不改 3000 正式页面或经济层。3003 提供静态预览，仅该文件夹可访问。原始平台 Logo 原样复制为 `logo.png`。

包含发行列表、运行列表的数据形态预览、Curve 操作终端、明暗切换、自选、筛选、图表类型/范围、金额/MAX、超余额禁用与确认弹窗。所有涨跌、历史路径和交易均为固定设计样例；估算只为展示布局，不是协议报价。运行终端明确提示留待后续步骤，不把 Curve 表单冒充 Operating。

不接钱包，不写模拟资产或正式存储，不替换真实行情。确认主题和布局后，应把结构迁入实际共享组件，连接原数据层，而非将静态脚本复制进正式终端。
