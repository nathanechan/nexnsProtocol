# 资料区与字体修正

运行项目资料使用独立卡片，修正内容紧贴边界、标签和值分布过散以及长文本换行。桌面标签和值按比例分列，窄屏采用 86px 标签列；简介、合约、时间、ID 和链接受内容宽度约束，不依靠裁切隐藏溢出。缺失链接显示“暂无项目链接”。

操作输入、按钮、摘要数字和页头价格统一到资料区使用的 Arial / Microsoft YaHei / PingFang SC 字体栈，保留原字号层级。未改写用户元数据、合约或资金规则。

按用户要求移除全站可见的模拟环境页脚，以及独立样板的环境文案；保留源代码中的模拟实现与不公开的内部工具，正式发布边界继续检查。动态数据运行方式不变。

254 项单元测试通过；资料页中英 × 明暗 × 1440/768/390/320 共 160 项浏览器断言通过，覆盖行边界、无横向溢出、输入与资料字体一致、可见环境文案移除。截图在 test-results/info-refinement/，构建、lint、格式及发布检查日志在 test-results/info-refinement-*.log。

本轮没有推送仓库。
