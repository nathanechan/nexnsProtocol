# 第 3 步 · 正式终端与市场工具栏修正

市场顶部改为显式网格工具栏：桌面为阶段入口、筛选、搜索同一行；平板和手机按宽度换行，不再用负边距与绝对定位。移除重复可见标题，仍保留页面 h1 供辅助技术使用。

列表原“人数”改为“地址 / Addresses”，表示原有参与地址数量；不把这一列改成代币合约地址，也不改统计值。终端对应使用“参与地址”，合约身份仍在项目栏。

## 操作终端

- Curve / Operating / 迁移共用 V3 主题与共享导航。终端页提供主题切换并沿用用户保存偏好；其他产品页面主题推广留在第 4 步。
- 桌面为指标与图表在左、352px 操作面板在右。手机操作区域先于市场指标和图表。
- Operating 的个人仓位、质押、覆盖率、可领取摘要移到表单下方“我的资产”，默认折叠。参与、质押、解除质押和领取的原表单与执行边界继续使用。
- 终端名称只显示简称，保留合约、管理入口和异常价格状态。买卖、参与/质押/领取统一品牌蓝选中，输入采用等宽大字号，Curve 补 MAX；原运行 MAX 保留语义标签。
- Curve 保留理论发行曲线，另提供成交报价历史视图。历史来自已保存的交易报价快照，无历史显示空状态，不从理论曲线制造时间行情。默认理论曲线保持新项目可理解的发行进度。页头 Curve 涨跌与市场列表采用相同快照来源。
- Curve 进度百分比只在主进度条显示，指标条保留距离完成金额、成交量和参与地址。
- 迁移状态、确认框身份、不可赎回本金提示及价格异常限制不变；不增加后台操作。

验证证据位于忽略目录 `test-results/v3-terminal*` 和 `test-results/v3-market*`，包括双主题/双语桌面、390/320 窄屏、首屏按钮、模拟买入生成历史、刷新持久化、操作切换、市场排序/自选及异常价格检查。真实手机软键盘仍需实机验收。

本轮没有推送仓库。下一步推广资产、创建、工作室、协议与 NEXNS 等剩余页面，并统一完成全站验收。
