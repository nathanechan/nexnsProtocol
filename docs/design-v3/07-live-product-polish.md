# 全局修正 · 持续市场模拟

## 数据运行

展示层行情改为每 4 秒更新，加入幅度有限的短周期变化，沿用统一 referencePrice、质押价值与历史源；同一项目在列表和终端不会各取一个随机数。运行活动和参与地址计数采用同一时间节奏。时钟不自动结算或发放个人奖励。

Curve 每约 8 秒由独立模拟交易者执行受资金/库存约束的买卖。复用 quoteBuy / quoteSell、手续费、净储备和成交量计算，写入真实模拟 ledger 与报价历史。每项目交易者初始预算为 25,000 USDT，库存和预算随交易记账并持久化，不改当前用户 exactBalances、currentUser 或 operatingBooks。接近完成时缩小买单，不由背景交易强制触发迁移。活动记录上限 384 条，隐藏标签页停止定时工作，返回时有限恢复，不回放无限交易。

这仍是明确标记的模拟环境，不是真实链上成交。无获利排行、假倒计时或擅自执行领取、结算、财库动作。

## 界面与表达

- 去掉市场列表内重复的发行/运行入口，保留全局导航。
- 运行项目详情六个标签在内容边界内换行，手机为两行布局。
- 深色搜索默认透明，悬停使用主题表面；统一图表范围悬停状态。
- 移除“操作 ↓”，把终端“切换项目”替换为直接打开全局搜索。
- 去掉 NEXNS 页面“进入 NEXNS 终端”按钮。介绍改为核心代币连接发行、协议参与与生态流动性，数据区说明供应、销毁、流动性和项目连接，不用交易池机制代替产品介绍。
- 创建步骤改为项目信息、项目链接、确认创建；市场/资产/协议等主要页面文案复查保留必要身份、金额、费用与风险信息，不增加工程流程说明。未宣称逐字重写所有帮助和条款。
- 金额变化短暂呈现涨跌色，遵守减少动态效果偏好。其余资金和奖励不会为制造活跃感而随机变化。

## 证据

254 项单元测试通过，包括交易者库存/资金约束、用户余额与奖励账本隔离、重复 tick 不重复成交及持久化。
