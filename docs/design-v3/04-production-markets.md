# 第 2 步 · 正式发行 / 运行市场页

3000 的发行与运行页面采用 V3 市场布局，不再依赖独立样板的数据与脚本。保留阶段筛选、平台币固定、自选身份、排序方向和规范合约路由。只显示代币简称，用户原始名称字段及全局搜索仍保留。

加入 Lucide 搜索、趋势和主题控件。两个市场页支持系统偏好、手动明暗切换和本地主题记忆；样式作用于市场及其共享导航/弹窗，其他页面主题推广留在后续步骤。桌面增加趋势列；手机采用紧凑行、行内涨跌和独立排序控件。

运行走势由现有 referencePrice 和一致的时间窗口计算，不加入随机行情。Curve 既有记录没有报价历史，本轮为新成交补记 priceBefore / priceAfter 展示字段；估价、余额、手续费、库存、迁移和奖励计算不变。旧记录没有报价时展示暂无走势和缺失涨跌，不用理论曲线伪装时间走势。

本轮没有把原样板动态条移入正式产品，因为静态示例不能作为真实模拟活动。后续如加入，应读取规范活动源并保留阶段语义。

验证：252 项单元测试通过；正式浏览器双语 × 4 宽度 × 双主题以及搜索、自选、排序、刷新检查共 224 项通过；生产构建包含类型检查通过。日志与截图位于忽略目录 test-results/v3-market*。视觉审核不由测试数量代替。

第 3 步继续重构 Curve / Operating 操作终端；第 4 步完成其余页面与全站验收。本轮未推送仓库。
