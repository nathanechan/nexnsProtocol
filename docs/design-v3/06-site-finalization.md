# 第 4 步 · 全站双主题与验收

资产、创建、工作室、协议、NEXNS，以及既有市场和终端，现在共享同一套主题角色。`site-v3.css` 定义明暗画布、表面、文字、边框、品牌、语义色；功能页保留自己的布局。所有页面显示主题按钮，首次绘制前读取选择，缺省跟随系统，手动偏好本地保存。

## 完成内容

- 导航、底部导航、产品菜单、搜索、钱包和确认弹窗同步主题。
- 资产摘要、领取区域、表格、空状态、创建表单、工作室指标、协议公开结果和 NEXNS 核心资产表面统一；修复表格单元格残留白底。
- 页面功能切换改为蓝色选中的 segmented control；主按钮为品牌蓝，次按钮为中性表面，涨跌和异常继续使用语义色。保留键盘焦点与减少动态效果偏好。
- 普通项目入口、资产领取行、结算标题及项目筛选使用简称，合约身份与用户原始名称字段保留；创建填写、编辑和明确元数据展示不改写品牌资料。
- 相同眉题和标题不再重复显示；空说明不占位。资产空状态不新增矛盾的领取标题。

## 验收与边界

252 项单元测试通过。浏览器检查包括九类页面 × 中英 × 明暗 × 1440/768/390/320，主题恢复、表格表面颜色、弹窗与横向溢出；终端首屏操作与模拟买入、历史持久化、异常价格限制、正式环境入口；另通过创建往返、品牌内容保存、模拟买入到账和非空资产页检查。

结果、截图与精确计数位于忽略目录 `test-results/v3-site-*.log` 和 `test-results/v3-site/`。自动化通过不代表审美排名；最终视觉仍由用户审核。真实手机软键盘及系统浏览器触感体验仍需实机验收。

本轮没有增加经济规则或真实链上执行，没有安装插件或依赖，没有推送仓库。四步重构的代码工作已完成，正式预览在 localhost:3000；3003 仍是独立设计样板，不是正式产品入口。
