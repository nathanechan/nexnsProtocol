# NEXNS 视觉升级 · Step 1

## 本轮交付与范围

独立预览地址：`/visual-preview`；运行终端：`/visual-preview?view=operating`。
发行、运行、资产及原有项目地址保持原版本。本轮没有改变 Curve、迁移、参与、质押、结算、领取、数据模型或金融持久化。
预览直接复用已有市场数据、项目终端与模拟操作，不复制第二套财务逻辑。预览操作仍会使用同一份本地模拟状态。

## 当前视觉诊断

1. 信息层级偏平：项目、价格、数字、说明文字的字号与重量区别不足，关键操作不够集中。
2. 样式债务：全局 CSS 经过多轮覆盖，类似控件的密度与间距不一致。后续需要按基础组件和页面整理，而不是继续全局补丁。
3. 品牌识别偏弱：通用渐变项目标识、细小文字与低对比表格容易形成模板感；项目品牌体系需要在后续步骤完善。
4. 终端空间分配：桌面常驻项目列表占用图表空间，手机表单存在较多留白，内容与动作之间的层次可以更明确。
5. 状态反馈：需要完整统一 hover、pressed、focus、disabled、pending、error、success，而不只是默认外观。

## 方向 01：浅色、专业、精确

保留白与浅灰基底、深蓝文字和蓝紫品牌色。区分页面底、内容表面与交互表面；大面积不使用渐变、发光与彩色背景。少量渐变只出现在既有项目图标和细进度条中。

| 项目         | 候选规范                                     |
| ------------ | -------------------------------------------- |
| 页面底色     | `#F4F6FA`                                    |
| 内容表面     | `#FFFFFF`                                    |
| 主文字       | `#17253D`                                    |
| 次要文字     | `#718096`                                    |
| 结构线       | `#E9EDF3`                                    |
| 品牌操作色   | `#4164ED`                                    |
| 主要选中态   | 深蓝 `#203454`，白字                         |
| 字体         | 系统无衬线栈，中英文配套；本轮不外部加载字体 |
| 页面标题     | 桌面 34px，手机 28px                         |
| 核心数字     | 24–29px，等宽数字特性                        |
| 列表文字     | 桌面主名称 14px；手机主名称 12px，数字 11px  |
| 内容圆角     | 桌面 15–18px；手机 13–14px                   |
| 控件圆角     | 7–11px，按控件层级统一                       |
| 主要操作高度 | 44px；金额输入 56px                          |
| 动效         | 状态过渡约 100–160ms；尊重减少动态效果偏好   |

以上是本轮样板候选，不代表已替换全站设计系统。Step 2 应将通过评审的值整理为正式 token 和基础组件，并验证小字号对比度与触控目标。

## 发行样板

保留项目 / 价格 / 涨跌 / 发行进度 / 人数与现有四个发现标签。用深蓝选中态、白色内容面、细结构线与更明确的字重建立层次。
星标与项目链接保持分离。表头排序留在预览页；正常项目链接仍进入现有正式终端。Curve 涨跌无足够历史时仍显示“—”。

## 运行终端样板

桌面用紧凑项目选择器替代预览内的常驻项目列表，形成图表与操作双区。手机按指标、图表、操作、详情排列；压缩操作区继承的固定最小高度。
项目价格、质押数量、金额、趋势及个人状态仍来自共享数据。参与、质押、领取沿用原组件。预览工具栏只用于评审，不作为未来正式产品文案。

## 下一步推广顺序

确认本轮方向后，再开展 Step 2：把按钮、输入、标签、弹窗及状态整理为正式组件与 token。随后才是市场列表、终端、其他页面与手机最终验收。
本轮不承诺已完成全站视觉升级，不新增深色主题，不补造价格历史，不自动推送或部署。
