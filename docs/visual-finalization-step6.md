# Step 6 · 最终移动端与交互一致性

本轮以 Step 1–5 已完成的正式页面为基础，收尾移动端、横屏、键盘焦点、弹窗与减少动效设置。

## 修正

- 手机输入框、文本域、选择框采用 16px 字号，降低移动浏览器输入时自动放大的问题。金额输入保留现有更大字号与数量单位。
- 页面滚动预留顶部导航与底部安全区；表单和主要操作增加滚动边距，键盘焦点更容易完整露出。
- 搜索等弹窗限制滚动传递；短横屏减少垂直留白，保留内部滚动和关闭操作。
- 产品菜单与导航使用共享短时颜色反馈，遵循系统减少动态效果设置。原有数据更新与动画时钟不变。
- 保留现有明确焦点环、加载/禁用、成功/失败反馈，不新增协议或后台控制。

修正集中于 `src/app/final-polish.css`。经济、费用、收益、执行、持久化、搜索排序和项目身份规则没有修改。

## 验收

新增 `scripts/final-step6-browser-check.mjs`，覆盖中英文的 320×640、390×844、768×1024、844×390、1440×900：九个正式页面无横向溢出、唯一标题、手机输入字号、搜索弹窗边界和 Escape、创建按钮焦点与底部导航避让、减少动态效果。

其余使用现有市场、自选、项目终端、财务操作、资产领取、创建、工作室、协议和实时模拟浏览器套件。完整单元测试、lint、格式与生产构建另行执行。最终结果和截图在忽略目录 `test-results/final-step6/`。

浏览器验证使用 Windows Edge 的响应式视口与触控模拟；未声称经过实体 iPhone / Android 或其屏幕键盘验收。本轮不推送或部署，生产环境部署仍需独立验证。
