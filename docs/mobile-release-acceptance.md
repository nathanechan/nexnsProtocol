# 发布前与实体手机验收

## 正式构建

正常发布必须省略 `NEXT_PUBLIC_NEXUS_DEMO_CONTROLS`，或设为非 `true`。该变量为构建时开关，修改后需要重新构建。

`/simulation-console`、`/visual-preview`、`/visual-preview/components` 在正常生产构建返回 404。开发模式或明确开启测试开关的构建仍可评审。`/design-system` 始终不可用。

本轮使用关闭测试开关的生产构建验证正式页面和移动布局；不包含链上生产集成。操作仍为前端本地模拟。

## 实体手机待验收

电脑本地入口：`http://localhost:3000`。手机需要与电脑同一网络，访问电脑局域网 IPv4 地址的 3000 端口；手机中的 localhost 指手机本身。若系统防火墙阻止访问，需按设备实际网络情况处理，不能以浏览器模拟代替连接成功。

建议使用 iOS Safari 与 Android Chrome，各检查一次：

1. 发行、运行列表上下滚动，自选星标和项目点击互不误触。
2. 搜索输入、清空、合约搜索、打开项目；软键盘出现后搜索和关闭按钮仍可用。
3. 项目页买卖金额输入：键盘弹出与收起后，页面没有异常放大、横向位移或按钮遮挡；确认与关闭可点。
4. Operating 项目的参与、质押、解除质押与领取，确认金额/单位、加载、成功反馈及资产同步。
5. 资产标签可横滑，领取卡片按钮不与底部导航重叠。
6. 创建三步前后切换保留输入；软键盘弹出时下一步可达，图片选择返回后布局正常。
7. 横屏与竖屏切换；弹窗内容可滚动到底并关闭。刘海/底部手势区不遮挡导航。
8. 开启系统减少动态效果，再检查标签、菜单与确认操作。

记录手机型号、系统/浏览器、页面、操作、实际结果。实体机检查尚未执行，不能将 Edge 响应式验收计作实机通过。

## 发布顺序

实机反馈修正 → 审核最终差异 → 同步仓库 → 检查托管平台构建与线上关键路径。本轮不自动推送或部署。
