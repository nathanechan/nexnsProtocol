# Step 2 · 两套旗舰方案评审

启动独立静态预览后访问：

- A 数据工作台：<http://localhost:3001/02-flagship-prototypes.html?design=a>
- B 操作聚焦：<http://localhost:3001/02-flagship-prototypes.html?design=b>

顶部深蓝工具条属于评审工具，可切换方案和正常运行、有可领取、暂无历史、价格异常；不属于正式产品。两套共用品牌、项目身份、数字与表单样例。默认桌面/手机都以相同参与态比较。

## 方案差异

|          | A 数据工作台                           | B 操作聚焦                                 |
| -------- | -------------------------------------- | ------------------------------------------ |
| 桌面     | 大面积趋势与四指标在左，操作在右       | 操作在左先被看到，右侧无外框数据区作为支持 |
| 容器     | 一块连续数据表面、一块操作表面         | 单一重点操作表面、更多白色留白             |
| 手机     | 精简数据与可收起趋势在前，底部操作锚点 | 表单在前，项目数据和图表在后               |
| 适用判断 | 重视项目观察和数据比较                 | 重视参与、质押与领取的直接性               |

这两套尚未被选为正式方案；视觉等级需由用户结合真实尺寸评审，不用自动化检查数量替代审美认可。

## 可体验范围

- 方案/状态切换；参与、质押、领取标签；金额输入、快捷金额、全部；余额超限禁用和明确提示；确认预览、Escape 关闭；手机趋势折叠与操作锚点；复制固定示例合约。
- 有可领取示例为 16 FIELD，到账示例为 13.6 FIELD；数据、曲线与个人仓位均为固定比较样本。曲线是质押数量示意，明确标注示例，未接入行情和经济引擎。
- 确认只弹出身份与金额，不执行、不结算、不持久化、不修改资产。原有不可赎回提示保留。
- 搜索、导航、时间范围和下方详情非本阶段接入范围，点击明确说明预览边界；不假装已经执行或加载真实数据。
- 价格异常样本用于展示依赖有效价格的参与操作禁用。真实不同动作的价格校验、精度、手续费、仓位收益与其他协议限制，Step 3 必须复用现有执行/读模型，不能使用此页面的示意计算替换。

## 本阶段评审问题

1. 桌面更认可数据在前还是操作在前？
2. 手机更认可先看趋势，还是直接进入操作？
3. 正式 Logo、品牌蓝、海军蓝、数字与留白是否符合品牌预期？
4. 两套共同仍不足的地方在哪里？可以组合取舍，但应形成一个明确旗舰方向。

确认方向后才进入 Step 3 真实旗舰实现。本阶段未修改正式路由、原组件、经济逻辑、依赖或账户数据，也未推送。

预览文件是 HTML/CSS/JS，服务器仅需读取 `docs/design-v2/`；截图与检查记录在忽略目录 `test-results/design-v2-prototypes/`。项目脚本 `scripts/design-v2-prototype-check.mjs` 需要独立预览在 3001 端口运行。
