# Step 3 · 真实旗舰终端：桌面 A / 手机 B

用户已确认桌面采用 A 数据工作台、手机采用 B 操作聚焦。真实页面使用 `/economy/[chainId]/[contract]`，不再是 3001 的静态设计比较页。

## 已接入

- Operating 使用 `.terminal-flagship` 标记，样式集中在 `src/app/flagship-terminal.css`。桌面四项项目指标与趋势形成连续数据区，右侧 360px 操作区；手机和平板将操作区放在指标、趋势之前。
- 移除 Operating 指标条中的重复价格；页头保留现有参考价格和涨跌。简称/全称、链/合约、必要状态与分享保持原有身份规则。
- 正式六边形 N 的路径、比例与 `#2464EB` 描边来自用户原始 SVG；平台默认图标不再使用蓝青渐变方块。平台上传的有效 Logo 仍按现有规则优先。普通项目的自定义品牌不变。
- 旗舰页面使用品牌蓝、海军蓝、精确分隔线与较少的外框。真实质押图表使用品牌蓝，数据、时间范围、指针/键盘读数及空历史逻辑不变。
- 操作区采用清晰金额输入、选中下划线、48px 主按钮；减少旧固定空高，并保持跨标签的按钮稳定性。手机仍保留吸顶操作标签与操作锚点。
- 下方仓位、收益、邀请、公开结果和资料仍由现有组件提供，改为较轻的连续详情区。

## 与静态方案的区别

真实输入初始为空，按钮依据实际余额和报价禁用；不填入虚构的默认金额、仓位或领取收益。图表可以平坦或缺少历史，不复制方案的示意曲线。报价、单位、精度、参与限制、确认、处理中、失败重试和到账全部由现有 store / 经济读模型提供。

没有复制静态方案中的示意计算，也没有改变执行时间、协议规则、参与不可赎回提示、奖励口径或持久化。Curve 和迁移页面保留前阶段结构；共享平台默认图标更新为正式品牌。

完整单元测试；新增 flagship 浏览器检查覆盖中英 × 1440/1024/768/390/320，四指标、品牌路径、桌面分区与手机操作优先、参与/质押/领取切换、截图和溢出。已有财务流程、失败恢复、实时图表、四生命周期、搜索切换与按钮稳定性继续回归。
