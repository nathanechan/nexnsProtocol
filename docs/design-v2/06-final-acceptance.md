# Step 6 · 最终浏览器验收

本轮保留桌面 A / 手机 B 的旗舰布局与全站 V2 系统，检查响应式、内容边界、操作状态和正式发布环境。浏览器通过代表已检查范围的功能证据，视觉效果仍需产品方审核。

## 本轮修正

- 终端和市场列表中可能截断的长简称增加完整文本提示；简称、全称和合约身份保持原数据。
- 动态数据回归脚本适配已经确认的四项指标条与页头价格，不恢复重复价格。

## 验证范围

- 中英文、320/390/768/844 横屏/1440 等视口；九类页面溢出、输入字号、键盘焦点、搜索弹窗和减少动态效果偏好。
- 通过真实创建流程建立长名称、12 位简称、长简介和同名项目；核对独立合约路由、搜索、大金额禁用反馈及确认框边界。
- 价格异常时参与不可提交；保护状态按既有规则处理。未放宽协议限制。
- 买卖、参与、质押、解除质押、结算、领取、资产同步、刷新持久化和图表/列表数据一致性沿用真实模拟层回归。
- 正式构建需要关闭演示控制入口，检查开发页面不可访问。

日志、截图及实际检查计数记录在忽略目录 `test-results/v2-final/acceptance-report.md`。没有修改经济引擎、执行层和持久化规则，没有安装依赖或推送仓库。

## 尚需人工验收

真实手机软键盘、系统浏览器和触感体验尚未实机测试；浏览器视口模拟不能替代实机。全站审美与品牌认可由产品方审核，不以测试数量推断已达到任何行业排名。
