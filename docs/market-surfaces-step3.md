## 简称与全称纠正

用户要求：外部列表首先显示代币简称；操作页简称在前，全称在后。

| 场景                   | 展示                                 |
| ---------------------- | ------------------------------------ |
| 发行 / 运行列表        | 主行 `FIELD`，次行 `Mireva`          |
| 搜索结果               | `FIELD` 在前，`Mireva` 为次要文字    |
| 操作页标题             | `FIELD` 在前，`Mireva` 在后          |
| 操作页标题下           | 仅保留合约等必要信息，不再显示交易对 |
| 资产项目链接及领取项目 | 简称在前，全称次要                   |
| 数量与操作输入单位     | 保持 `FIELD`，参与资金仍为 `USDT`    |
| 同名简称与全称         | 终端标题不重复显示同一文字           |

没有把 Symbol 和 Name 两个数据字段交换或重命名，没有修改创建者保存的品牌原文。搜索仍同时支持合约、项目 ID、Symbol、Name、Creator。最终身份仍是 chainId + 合约地址，同名与同简称项目保持独立。
确认弹窗的“项目”“代币”分别对应全称与简称，不混淆有标签的元数据。

## 本轮边界
