# Step 5 · 资产、创建、工作室与公开结果

沿用 Step 2–4 的浅色画布、白色圆角卡片、深蓝选中态与统一操作组件，正式应用到 `/portfolio`、`/create`、`/studio/[projectId]`、`/nexns`、`/protocol`。

- 资产：余额摘要、逐项目领取卡片、分类标签、持仓与历史表格统一层级。保持各代币独立领取，没有合并跨项目金额或改变估值。
- 创建：三步进度强调当前步骤，表单和确认区使用一致的间距、边框和操作区；规则仍收在展开帮助中。保留原字段、校验、品牌内容和创建逻辑。
- 工作室：项目身份、指标、资料编辑与公开结果使用共同卡片；资料保存显示共享加载状态。桌面详情卡片各自按内容高度排列，避免短内容被拉成空白长卡。
- NEXNS 与协议：延续同一页面标题、数据表格、筛选器、指标和公开事件外观，所有数值及查询来自现有读模型。
- 手机：数据表格保留双列记录卡片；标签可横向浏览；领取按钮有 44px 高度；创建规则移到表单下方。

样式集中在 `src/app/account-surfaces.css`，只作用于 `.secondary-page`；不影响市场和项目终端的布局。没有修改协议参数、资金执行、结算、模拟时钟、存储和路由语义；没有添加后台操作。

验收使用完整单元测试、生产构建、已有 secondary / final acceptance / detail correction 浏览器套件以及窄屏视觉检查。截图与结果在忽略目录 `test-results/`。本轮停在 Step 5，不推送和部署。
